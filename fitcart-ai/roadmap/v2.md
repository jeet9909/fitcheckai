# Roadmap — V2

**Theme:** improve **accuracy, conversion, and engagement** on the validated MVP. Deepen the moat (fit data + personalization). Still no dependency on partner cart-sync.

## Objectives
1. Raise avatar/fit accuracy (multi-photo).
2. Increase conversion (variant swap, compare, better recommendations).
3. Grow engagement/retention (personalization, sharing, saved outfits depth).
4. Begin monetization depth (Pro tier maturity, Studio renders).

## Features
| Area | Feature | Value | Complexity |
|---|---|---|---|
| Body | **Side + back photos** → better shape/measurements (±3–6%) | High | M |
| Body | Improved skin-tone/posture fidelity | Med | M |
| Try-on | More angles, better consistency, layering v1 | High | H |
| Viewer | Variant/color swap live, **compare two outfits** | High | M |
| Fit | Layering compatibility; per-brand true-to-size calibration from feedback data | High (moat) | M |
| Outfit | **Learned outfit embeddings** (pgvector) + personalization | High | H |
| Outfit | Trend score (trend data feed) | Med | M |
| Texture | Super-resolution enhancement | Med | M |
| Recs | "Complete the look" recommendations | High | M |
| Social | Share renders, lookbooks | Med | M |
| Monetize | Pro tier polish, **Studio HD renders**, brand-featured (labelled) | High | M |
| A11y | Expand accessibility; begin **seated-posture avatar** work | High (inclusion) | H |
| Data | Fit-feedback flywheel powering calibration at scale | Very High (moat) | M |

## Success criteria
| Metric | Target `ASSUMPTION` |
|---|---|
| Fit accuracy ("was accurate") | ≥ 80% |
| Try-on → add-to-cart | ≥ 32% |
| D30 retention | ≥ 15% |
| Pro conversion | ≥ 4% |
| Recommendation CTR | ≥ 15% |

## Dependencies
- Sufficient fit-feedback volume from MVP to calibrate.
- Trend data source (partner/feed).
- Vector infra (pgvector) — already provisioned.

## Still deferred to V3
True real-time 3D cloth sim · partner cart-sync · full prosthesis-aware avatars · B2B SDK · fashion analytics product.
