# Roadmap — V3

**Theme:** advanced realism, partnerships, and new revenue surfaces. This is where the aspirational features (true 3D, cart-sync) become real — **gated on partnerships and validated unit economics**, not shipped on hope.

## Objectives
1. **True 3D** try-on (textured avatar + garment simulation) where assets allow.
2. **Partner cart-sync** for stores that sign on.
3. **B2B try-on/fit SDK** (high-margin, durable revenue).
4. Full **inclusion** (seated/prosthesis-aware avatars, adaptive fashion).
5. **Fashion analytics** product (aggregate, consented).

## Features
| Area | Feature | Label |
|---|---|---|
| Try-on | Textured 3D avatar (multi-photo/video), **cloth simulation** on partner-provided 3D garment assets | V3 · needs assets |
| Viewer | **Real-time 3D free-camera** viewer (swap into `OutfitViewer` interface) | V3 |
| Integration | **Partner cart-sync** via OAuth `PartnerAdapter` | **PARTNERSHIP REQUIRED** |
| Body | Gaussian-splat / neural avatars (experiment) | V3 · research |
| Inclusion | Seated-posture + prosthesis-aware avatars; adaptive-fashion metadata | V3 (inclusion) |
| B2B | **Try-on + Fit SDK / white-label** for retailers/brands | New revenue |
| Analytics | Aggregated, anonymized fashion/fit insights product | New revenue · consent-gated |
| Expansion | SEA / Middle East localization | Geo expansion |

## Why these are V3 (honesty)
- **True 3D** needs 3D garment assets stores don't provide → requires **brand partnerships** or asset generation R&D.
- **Cart-sync** is impossible via official APIs today → requires **signed partners** (leverage earned by MVP/V2 traffic).
- **B2B SDK** needs a proven, differentiated fit engine (built via the V1–V2 data flywheel).

## Success criteria
| Metric | Target `ASSUMPTION` |
|---|---|
| ≥1 platform/brand partnership live (cart-sync or assets) | Yes |
| B2B SDK pilot customers | ≥ 2 |
| 3D try-on quality vs 2D (user preference) | > 60% prefer |
| Blended margin improvement (self-host + B2B) | Positive |

## Strategic note
V3 is where FitCart transitions from "clever consumer app" to "**infrastructure for fashion fit**" — the B2B SDK + fit-data moat is the defensible, high-margin endgame if consumer distribution gets crowded by big-tech (see `docs/risks.md` B1, `investor/competitive-moat.md`).
