# Competitive Analysis & Attack Strategy

Companion to `research/competitors.md` (deep profiles + ratings). This file is the **strategy layer**: positioning, the attack matrix, and how we out-execute each threat.

## 1. Competitive landscape map (positioning)
Two axes: **Cross-store coverage** (x) × **Fit/outfit intelligence depth** (y). See `diagrams/competitive-positioning.md` for the chart.

- **Top-right (open):** FitCart AI — high cross-store × high fit-intelligence. **Nobody else is here.**
- **High realism, low cross-store/fit:** Google Doppl, Snap, Walmart.
- **B2B avatar/try-on:** Reactive Reality, Vyking, Fashable.
- **Single-catalog marketplaces:** Myntra, Ajio, Amazon, Flipkart, Nykaa, Meesho.

## 3. "Why would a user choose FitCart AI?"
1. Answers **"will it fit me?"** with a score — not just "how it looks."
2. Builds a **whole outfit across the stores they already use**.
3. **India-first** body diversity, sizing norms, price sensitivity.
4. **Trust** — privacy-first body-data handling.

## 4. "What stops a competitor from copying us?"
Honest answer: *technically, a giant could.* Our defensibility is **not** the try-on model (commoditizing). It is:
- **Proprietary fit/outfit + purchase/return/satisfaction data** → compounding accuracy (network effect).
- **Structural neutrality**: marketplaces won't route users to competitors; that lane is ours by construction.
- **Trust brand** on body data in a newly-regulated (DPDP) market.
- **Focus & speed** in a niche giants treat as secondary.

## 5. Where we do NOT win (state it plainly)
- **Raw generative image realism** — Google/others lead. We aim for "good enough + honest," not best-in-class pixels.
- **Distribution** — we lack Google/Amazon reach; we win via affiliate + niche love + partnerships.
- **Cart-sync today** — platform reality blocks it; we don't pretend otherwise.

Acknowledging these openly is what makes the rest of the deck credible.

## 6. Strategic response if a giant enters our exact niche
1. Deepen the **fit data moat** (the one thing they can't shortcut).
2. Lock **India brand/platform partnerships** for cart-sync + exclusive catalog depth.
3. Pivot emphasis to **B2B fit/try-on SDK** (sell the shovels) if consumer distribution gets crowded.
4. Own **inclusion** (plus-size, accessibility, adaptive fashion) — the segment giants under-serve.
